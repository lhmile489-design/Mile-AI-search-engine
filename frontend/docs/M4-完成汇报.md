## 知识点素材

- **精确角标高亮**：通过 `markerStart`（角标在原始 report 里的 UTF-16 偏移）与后端 `citations` 数组的 `markerStart` 字段对应，实现同一信源多次引用时每个角标只高亮对应的那一句。对应代码：`src/lib/highlight.ts:rangeForMarker()`、`src/lib/citations.ts:markerOffsets()`。
- **remark position.offset**：mdast text 节点的 `position.start.offset / end.offset` 记录了它在原始 Markdown 源文件里的字节（UTF-16 码元）位置，可以把解析后的 value 映射回原文，用于计算精确偏移。对应代码：`src/lib/citations.ts:50`。
- **Markdown 转义检测**：`\[1\]` 在 remark 解析后 text.value 是 `[1]`，但在原始 source slice 里是 `\[1\]`。通过检查候选角标前一个字符是否为 `\` 来排除转义写法，避免误识别。对应代码：`src/lib/citations.ts:markerOffsets()` 的 `filter` 步骤。
- **缓存命中双级标注**：L1（子检索词缓存）时只有部分阶段 `trace.cacheHit=true`，用各阶段独立标注；L2（全量缓存回放）时 `done.cacheHit=true` 且所有阶段均为 true，用 `isReplayingCache()` 在 HeronStepper 标题和 ResultToolbar 处显示全局 Badge。
