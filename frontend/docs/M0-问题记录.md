## 前端内部，已处理或下一轮处理

| 编号 | 问题 | 处理 |
| --- | --- | --- |
| P1 | 派发要求用 `curl.exe -N` 记录事件到达时间 | 改用自写的 `scripts/sse-probe-client.mjs`（fetch 读流，毫秒级时间戳并打印 `content-encoding`），比给 curl 输出加时间戳更准。复现命令见下 |
| P2 | `Card` 的 `onClick` 渲染为 `<button>`，按钮内只能放行内内容 | 已在类型注释写明；需要放块级内容时用 `href`（渲染为 `<a>`）。M3 如有可点击且含标题的卡片，按此约束写 |
| P3 | 主按钮按下态的 `--shadow-accent-press` 是直接切换，没有过渡 | §8 要求只过渡 transform / opacity，按下是瞬时反馈，保持直接切换 |
| P4 | 开关焦点环用 Tailwind `ring-offset-2`，偏移色是 Tailwind 默认白色，不是令牌 | 在 `--bg` 灰底上看得到一圈白边，视觉可接受。如需严格令牌化，Q1 同步时加 `ringOffsetColor` 映射 |
| P5 | `globals.css` 的 `:focus-visible` 带 `border-radius: var(--radius-xs)`，会改写没有圆角类的元素本身的圆角 | 本轮组件都带 `rounded-*` 类，不受影响。规则来自 §6.6，是否收窄由主调度决定 |
| P6 | `body { overflow-x: hidden }` 会掩盖横向溢出 | 本轮截图验收没有依赖它：逐个元素量了边界，四个宽度都没有元素越出视口 |

## 复现命令（Git Bash，cwd 为 `frontend/`）

```bash
# SSE 探针：终端 1
node scripts/sse-probe-server.mjs
# 终端 2（dev）
BACKEND_ORIGIN=http://127.0.0.1:8001 node node_modules/next/dist/bin/next dev --port 3000
# 终端 3
node scripts/sse-probe-client.mjs "http://127.0.0.1:3000/api/probe/stream" dev-basic
node scripts/sse-probe-client.mjs "http://127.0.0.1:3000/api/probe/stream?count=3&delay=35000" dev-delay35
node scripts/sse-probe-client.mjs "http://127.0.0.1:3000/api/probe/stream?count=3&delay=35000&heartbeat=10000" dev-delay35-hb
# prod：BACKEND_ORIGIN 必须在 build 时设置；测完用默认配置重新 build，恢复 8000
BACKEND_ORIGIN=http://127.0.0.1:8001 npm run build && node node_modules/next/dist/bin/next start --port 3000
```
