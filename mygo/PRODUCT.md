## 1. 产品

本地运行的 AI 技术研报搜索引擎，桌面应用（mygo + WebView2）。用户是研究者、工程师、架构师。一次检索产出一份带引用角标的研报，每个结论都能点回原文段落。

原则：

1. 证据先于结论：每个论点挂信源，可反查。
2. 过程即思考：展示真实的检索轨迹，不用转圈等待。
3. 数字都是真的：耗时、计数、分数、共识度全部由 Go 端实算，算不出就不显示，不用占位值。
4. 双向联动：正文角标、信源卡片、原文片段互相高亮。

## 2. 界面状态机

只有三态，状态切换只在一个 reducer 里做：

```text
initial --提交--> retrieving --首个正文 token 到达--> result
retrieving --Esc 或停止--> initial（保留输入）
result --新检索--> retrieving
result --清空/新建--> initial
```

`result` 内用 `generating` 布尔区分生成中。生成中按 Esc：留在 `result`，保留已生成内容，标注「已中止」。

每次检索有 `runId`，晚到的帧（属于旧 runId）一律丢弃。45 秒无任何帧时前端提示「长时间没有响应」，只提示，不改状态、不登出。

## 3. 屏幕

窗口默认 1280x860，最小 960x640，记住上次位置（`StateKey`）。

**屏幕 1：首屏（initial）**。居中，最大宽 760px。顶栏（应用名、快捷键提示 Ctrl+K）、主标题（serif，一层，无副标）、搜索框、推荐问题（来自 Go 端，3 到 5 条，单行胶囊，点击即发起检索）。

**屏幕 2：检索中（retrieving）**。最大宽 1040px，双栏 7:5。左：步骤时间轴（改写、检索、重排、生成四阶段，各自状态与实测耗时，可展开看子检索词）。右：信源雷达，信源逐批追加，带分类标签，新卡片先显示骨架。顶部是只读的紧凑搜索栏。

**屏幕 3：结果（result）**。顶部单行控制条：问题、总耗时、信源数、缓存命中标签、视角切换（研报 / 观测台）、新检索。下面是推理摘要折叠条（已完成阶段数、总耗时、信源数，展开为简版时间轴）。

- 视角 1「研报」，60/40：左侧核心要点（3 到 5 条，各带角标）、共识度徽标、研报正文（Markdown、GFM 表格、代码高亮、LaTeX、OpenUI 卡片）、相关追问；右侧证据抽屉。
- 视角 2「观测台」：完整时间轴加信源雷达，含三项重排分数与总分。点信源跳回研报视角并定位抽屉。

窗口宽度小于 1100px 时证据抽屉改为右侧覆盖式。

## 4. 控件与行为

| 控件 | 行为 |
| --- | --- |
| 检索模式 | 通用 / 学术 / 代码，选项由 Go 端下发 |
| 信源范围 | 五类多选：预印本、代码仓库、规范、官方文档、技术博客，过滤在 Go 端生效 |
| 引擎 | 只列出已配置密钥的引擎；列表为空时禁用提交并提示配置 Key |
| 发送 | Enter 提交，Shift+Enter 换行；空输入禁用 |
| 停止 | Esc 或停止按钮，调用取消，Go 端取消在飞请求 |
| 引用角标 | 点击：定位并高亮对应信源卡片，抽屉内高亮被引句子；只高亮被点的那一个角标对应的句子 |
| 编号超出信源范围 | 按纯文本显示，不渲染角标 |
| 无原文片段 | 只高亮卡片，不报错 |
| 复制 BibTeX | 仅预印本信源显示；元数据不全时按钮禁用并说明原因；剪贴板失败给出提示 |
| OpenUI 卡片 | 交互视图 / DSL 源码切换；解析失败降级为源码视图，不消失；流式中按「部分成功」渲染 |
| 相关追问 | 3 到 5 条，点击直接发起新检索 |
| 历史 | 侧栏列表，点击恢复完整快照，不重新检索；可删除单条 |
| 缓存命中 | 全量回放时显示「缓存命中」，耗时显示本次实测值，不显示缓存里存的旧值 |

不做：深色模式、深度研究开关、多模型切换、登录与头像、付费入口、导出、分享。界面上的每个控件都必须有真实实现支撑。

## 5. 键盘

| 键 | 行为 |
| --- | --- |
| Ctrl+K | 聚焦搜索框 |
| Ctrl+B | 展开或折叠侧栏 |
| Enter / Shift+Enter | 提交 / 换行 |
| Esc | 检索中：停止；生成中：中止；抽屉打开：关闭抽屉并把焦点还给触发它的角标 |
| Tab | 可到达角标、信源卡片、历史项、所有按钮 |

## 6. 错误态

每种错误有可读原因和重试入口，错误码沿用 `../docs/接口设计.md` §12。

| 场景 | 文案要点 |
| --- | --- |
| 未配置密钥 | 说明缺哪个 Key，给出配置入口 |
| 网络 / 超时 | 说明哪个阶段超时，提供重试 |
| 外部 API 额度用尽 | 说明是哪个服务，提供切换引擎 |
| 主引擎失败自动降级 | 时间轴标注「已降级到 X」，流程继续 |
| 无结果 | 说明未检索到信源，建议放宽范围 |

## 7. 文案

默认简体中文，技术名词保留业界缩写（TMA、SMEM、CUDA、arXiv、FP8）。语气专业克制，不用口语和营销口号。无 emoji。

## 8. 首次运行

没有 Key 时进入设置页（不是空白）：填入 `LLM_API_KEY`、`TAVILY_API_KEY`，写入 `%APPDATA%\MileAISearch\.env`，不写日志、不回显明文。保存后无需重启即生效。

## 9. 与原项目的差异

| 项 | 原项目 | 本项目 |
| --- | --- | --- |
| 形态 | Next.js 网页 | mygo 桌面应用 |
| 通信 | HTTP + SSE | 绑定 + `mygo.Channel` |
| 搜索失败 | 回退到本地 mock 数据 | 报错，不用假数据 |
| 共识度 | 固定文案「100% 交叉验证一致」 | 按规则实算，算不出不显示 |
| 深度研究开关 | 有 | 不做（行为未定义） |
| 模型切换 | 有 | 不做 |
| 快捷键 | Cmd 系 | Ctrl 系 |
