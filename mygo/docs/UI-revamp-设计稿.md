# UI 升级设计稿：三栏工作台（harness 布局）

> 状态：草案 v0.1 · 2026-11-10。落地前先与 PRODUCT.md / DESIGN.md 对齐，改动以契约为准。
> 交互原型：`docs/prototype/harness-layout.html`，浏览器直接打开，右上切换三态与窗口宽度。

## 1. 设计目标

把「一个会滚动的网页」改成「一个工作台」。核心是三区职责单一、边界清晰：

- **左 · 目录区（nav）**：去哪。历史检索列表、视图切换、设置。不读内容。
- **中 · 内容区（canvas）**：读什么。同一时刻只呈现一态（输入 / 进度 / 研报），内部不再拆左右栏。
- **右 · 预览区（inspector）**：看这个的证据。信源卡片 + 原文片段高亮 + 属性。不导航、不输入。

## 2. 骨架

```text
1280px（默认宽）
┌────────┬──────────────────────────────────────────────┬───────────┐
│ RAIL   │  TOP BAR（标题 / 状态 / 视角切换 / 新检索）      │           │
│  64px  ├──────────────────────────────────────────────┤ INSPECTOR │
│        │                                              │  340px    │
│ 新检索 │              CONTENT（唯一滚动区）             │ 独立滚动  │
│ 历史   │   initial / retrieving / result 三态之一        │           │
│        │                                              │           │
│ 设置   │                                              │           │
└────────┴──────────────────────────────────────────────┴───────────┘

960px（最小宽）
┌────┬──────────────────────────────────┐
│RL64│  TOP BAR                          │
│    ├──────────────────────────────────┤
│    │  CONTENT                         │
│    │  右栏改为覆盖式抽屉（点角标/信源    │ ← 抽屉 380px
│    │  卡片才滑出，Esc/遮罩点按关闭）     │   遮罩压内容
└────┴──────────────────────────────────┘
```

## 3. 三区规格

### 3.1 左 · 目录区（rail + 可展开历史）

- 固定 **rail 64px**：图标纵列——新检索（顶部）、历史（中部）、设置（底部）。当前视图对应的图标呈激活态（`--primary-light` 底 + `--primary` 字）。
- 点「历史」图标：rail 右侧展开 **目录面板 260px**（`--sidebar` 底），列出历史检索；再点或选条目后收起，也可 Ctrl+B。收起后只留 64px rail。
- 目录面板顶部有分组小标头「历史记录」（`--text-label` + `--fs-micro`）；条目两行：问题（`--fs-ui` 粗体两行截断）+ 时间与信源数（`--fs-small` + `--text-2`）。当前条目 `--surface-active`。
- 960px：目录面板改为覆盖在内容上（遮罩 `--ink` 30% 透明），不是把中栏推窄。

### 3.2 中 · 内容区（canvas）

- 顶部固定 **工作条**：左问题标题（一行截断，`--fs-ui` 粗体），右侧依次是状态/耗时、视角切换（研报 / 观测台，分段控件）、新检索按钮。
- 下方是**唯一滚动区**，三态：
  - `initial`：垂直居中，宽 640px。serif 主标题 + 大搜索框（`--r-search`）+ 推荐问题胶囊。
  - `retrieving`：上为步骤时间轴（四阶段，占宽不限），下为信源雷达（卡片列表逐批追加）。
  - `result`：自上而下 = 推理摘要折叠条 → 核心要点 + 共识度 → 研报正文（max-width `var(--measure)` 居中，两侧留白）→ 相关追问。研报正文单行内不再放侧栏。
- 滚动只发生在这一层；顶栏与工作条不随内容滚动。

### 3.3 右 · 预览区（inspector）

- `result` 态宽 **340px**，`--sidebar` 底，左边 1px `--border`。顶部固定区：标题「证据 · N 个信源」+ 关闭（窄屏/覆盖式时才有）。
- 信源卡片列表独立滚动。卡片：编号徽标 + 标题链接 + 域名/分类/日期行 + 原文片段（默认截 4 行，可展开）。被点角标对应的卡片滚到可视区，卡片加 `source-active` 强调条，片段里对应句子用 `evidence-mark` 高亮。
- 双向联动：点角标 → 抽屉定位+高亮句子；点信源卡片编号 → 正文里指向它的角标全部高亮（F06 已实现）。
- <1100px 时变为覆盖式抽屉（宽 380px，右侧滑入，遮罩压内容）。

## 4. 三态在骨架中的呈现

| 态 | 左 rail | 中 content | 右 inspector |
| --- | --- | --- | --- |
| initial | 激活=新检索 | 居中表单 | 隐藏 |
| retrieving | 激活=新检索 | 进度+信源雷达 | 隐藏（或显骨架，不占交互） |
| result | 激活=当前视图 | 工作条+研报 | 证据抽屉 |

## 5. 层级与令牌映射

- 深度只用 4 级海拔：`--shadow-rest`（卡）、`--shadow-hover`、`--shadow-focus`（搜索框聚焦）、`--shadow-pop`（浮层/抽屉）。
- 分区靠**底色 + 1px 边**，不靠阴影：canvas 用 `--canvas`（最浅），inspector 与 rail 用 `--sidebar`（深一档），卡片用 `--surface`（白）浮在上。
- 强调色三处：`--teal` 只给品牌与检索类；`--primary` 给激活/链接/角标；`--evidence` 只给证据高亮。
- 禁止：渐变、卡片套卡片、多色分区、营销药丸、emoji。

## 6. 交互要点

- Esc：检索中停止 / 生成中中止 / 抽屉开时关抽屉并把焦点还给角标。
- Ctrl+B：开合历史目录面板。Ctrl+K：聚焦搜索框。
- 双向高亮：角标 ↔ 信源卡片，见 §3.3。
- 缓存命中：工作条显示「缓存命中」徽标 + 本次实测耗时。
