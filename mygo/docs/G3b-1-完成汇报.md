## 知识点素材

- UTF-16 与 UTF-8 偏移：Go 字符串是 UTF-8 字节，按 `[]rune` 取下标得到的是码点位置，而契约与 JS `slice` 用 UTF-16 码元；大于 U+FFFF 的字符（emoji）在 JS 里占 2 个单位。`textutil.UTF16Offsets` 先建 rune 到码元的映射表，`citations.go` 的 markerStart/sentenceStart/highlight 都经它转换，测试覆盖 emoji 代理对（`emoji_surrogate`）。线上校验：45 条 citation 的 markerStart 切片全部等于 `[n]`，mismatches=0。
- 共识度不用占位值：`cited=0` 时整个 `consensus` 为 `null`，界面不显示徽标；写 0% 或 100% 会让用户把"没有可验证的引用"读成"验证过"（`ComputeConsensus`，`citations.go`）。
- 失败不兜底：收尾调用失败或解析失败时 takeaways 为空、`related` 帧不发，trace 记 `finalize_failed` 与原因，界面如实少一块，而不是塞固定追问（`finalize.go`、`run.go`）。
- 先配平围栏再算偏移：偏移是相对最终正文的下标。若先算偏移再删掉未闭合围栏，删除点之后的所有 markerStart 都会错位，高亮落到错误位置（`run.go` 中 `BalanceFences` 在 `ParseCitations` 之前）。
- runId 契约：取消按页面生成的唯一 id，未知 id 不取消任何东西，避免迟到的取消打到新一轮检索（`registerRun`、`Cancel`）。
- Python 参考输出做测试预期：`gen_parity.py` 跑真实 Python 函数产出 JSON，Go 测试读它，改算法时两边差异立刻暴露。
