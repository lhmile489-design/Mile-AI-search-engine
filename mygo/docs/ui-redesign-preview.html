NVIDIA Hopper 架构（H100/H200）引入了 Tensor Memory Accelerator（TMA）单元，是 GPU 异步数据搬运的重要革新。TMA 能够在 SM 执行计算的同时独立搬运数据，从而显著减少内存访问延迟。

TMA 核心机制

TMA 使用 cp.async.bulk 指令族实现 Global → Shared Memory 的大块数据传输。与传统 cp.async 相比，TMA 支持多维张量描述符（Tensor Map），由硬件完成地址计算，CPU 开销降低约 40%。

性能数据

在 FlashAttention-3 中，TMA 带宽利用率从 H100 SXM5 的理论上限 3.35 TB/s 中实际达到 2.8 TB/s（83.6%），相比 A100 提升约 3.2×。
