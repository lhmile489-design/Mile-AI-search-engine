要求：

- 在真实服务上复现，不要只靠单测。思路：给 `_pipeline_task` 和 `run_pipeline` 的 `finally` 加临时调试日志，确认断开时哪个任务停在哪一行、`task.cancel()` 有没有被调用、任务是被取消还是自己结束的、是否仍有挂起任务。

- 验收：贴服务日志原文（含那一行）、断开前后 Tavily 与 DeepSeek 调用计数、`scripts/smoke.py --abort-test --log-file ...` 的实际 PASS 输出。

## 任务 3：F13 BibTeX（后端部分）

现状：`ranker.py` 里 `bibtex = None  # M2 阶段不生成`。

- 只为分类是 `preprint` 的信源生成 BibTeX，其余信源 `bibtex: null`。
- **只用真实元数据**：标题、作者、年份、arXiv 编号或 DOI 都来自检索结果或页面，缺任何一个必需字段就返回 `null`，不猜、不拼凑（决策 D4）。哪些字段算必需，你先实测几个真实 arXiv 结果后定，写进对接文档。
- 条目 key 稳定可复算（如 `作者姓氏+年份+标题首词`），同一篇论文两次生成结果一致。
- 注意转义：标题里的 `{`、`}`、`&`、`%`、`_` 要按 BibTeX 规则处理；UTF-8 无 BOM。
- 单测覆盖：元数据齐全、缺作者、缺年份、非 preprint、标题含特殊字符。
