## 任务：M0 前端依赖实测 + 基础组件

契约还没定稿，本阶段只做和接口无关的事情。

### 任务 1：npm 包核实

用 `npm view <包> name version dist-tags repository.url time.modified` 查下列包，写结论到 `frontend/docs/依赖核实.md`：

| 包 | 要回答的问题 |
| --- | --- |
| `@openuidev/react-lang` | 是否存在；存在的话，版本、仓库、是否导出 `Renderer`、DSL 语法和教程示例（`HardwareBenchmarkCard(...)` / `column(...)` / `row(...)`）是否一致。不存在就写「不存在」，并给出自写 DSL 解析器的初步方案（只写方案，不写代码） |
| `react-markdown`、`remark-gfm`、`remark-math`、`rehype-katex`、`katex` | 最新稳定版本，是否支持 React 19 |
| 代码高亮（候选：`rehype-highlight`、`shiki`） | 选一个，说明理由（包体积、流式渲染时的表现） |
| `framer-motion`（或其新包名 `motion`） | 当前推荐包名和版本 |

**只查，不安装。** 安装放到 M3，以免装了不用。

### 任务 2：SSE 经 Next.js rewrites 转发是否被缓冲

PRD §13 风险表里的一条。做法：

1. 在 `frontend/scripts/sse-probe-server.mjs` 写一个最小的 Node SSE 服务（只用 Node 内置 `http` 模块），监听 `127.0.0.1:8001`，路径 `/api/probe/stream`，每 300ms 推一条 `event: tick`，共 10 条。
2. 用 `BACKEND_ORIGIN=http://127.0.0.1:8001` 启动 `npm run dev`，分别用 `curl.exe -N` 直连 8001 和经 3000 转发请求，记录每条事件的到达时间。
3. 结论写进 `frontend/docs/依赖核实.md`：经 rewrites 转发时事件是逐条到达，还是攒到最后一起到达。如果被缓冲，调研可行的解决办法（Route Handler 自己转发、开发环境直连并配 CORS 等），只写方案。
4. dev 构建（`npm run dev`）和生产构建（`npm run build && npm run start`）都要测，两者行为可能不同。
5. 测完停掉所有进程，释放端口。

### 任务 3：基础组件（静态，无数据）

按 `DESIGN.md` §6 实现以下组件，放 `src/components/ui/`：

- `Button`（primary / secondary / ghost / disabled）
- `Chip`（静态 / 可点击）
- `Badge`（浅色 / 深色）
- `Card` 与 `Panel`（elevation-2 / elevation-3）
- `Switch`

要求：

- 只用 Tailwind 映射出来的类名，不写 hex、不写任意值、不写 `style={{}}`。
- 悬停的阴影变化按 DESIGN.md §8 用伪元素加 opacity 实现。
- props 全部 `Readonly<...>`；单文件不超过 300 行。
- 做一个临时预览页 `src/app/dev/ui/page.tsx` 展示所有组件和状态。这个页面只在开发环境可访问：生产构建时返回 `notFound()`。
- 图标用 `lucide-react`（已安装），禁止 emoji。

### 不要做

- 不写状态机、SSE 解析、三个屏幕（那是 M3）。
- 不按教程猜接口字段做 mock。
- 不修改 `../backend/`、`../docs/`、根目录文档。
