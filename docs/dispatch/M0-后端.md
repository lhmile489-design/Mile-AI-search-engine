## 任务：M0 外部依赖实测

目标：用真实密钥调用教程提到的每个外部依赖，确认它存在、怎么调、返回什么。结论决定 M1 的契约怎么定。**本阶段不写业务代码。**

### 前提

用户会把密钥写进 `backend/.env`（参照 `.env.example`）。如果某个密钥缺失，该项标「阻塞：缺少密钥」，继续测其他项，不要编造结果。

### 要测的依赖

| 编号 | 依赖 | 要回答的问题 |
| --- | --- | --- |
| P1 | DeepSeek API | 1. `GET /models` 返回哪些模型名（教程写的 `deepseek-flash` 是否存在）；2. OpenAI 兼容的 chat completions 流式调用能否跑通，首 token 耗时多少；3. 流式响应里是否带 usage（token 统计） |
| P2 | DeepSeek 搜索端点 | 教程说「直连 DeepSeek 搜索端点」。查 DeepSeek 官方文档，确认是否存在公开的搜索 API。不存在就写「不存在」并给出文档链接作为依据 |
| P3 | Tavily Search | 1. 请求字段：`search_depth`（`advanced`）、`exclude_domains`、`include_raw_content`、`max_results` 是否都生效；2. 返回字段的真实名称和类型（标题、URL、摘要、原文、发布时间、相关性分）；3. `exclude_domains=["arxiv.org"]` 时结果里确实没有 arxiv；4. 单次耗时 |
| P4 | QuickRouter Jev（`jev-1.14.0`） | 查是否存在这个服务和模型、接口地址、鉴权方式、请求与返回格式。教程里的 `choices` / `choice` / `probability` 字段是否真实。找不到任何官方来源就写「无法确认存在」 |

### 做法

1. 探测脚本放 `backend/scripts/probe_<依赖>.py`，用 `uv run python scripts/probe_xxx.py` 运行。用 httpx，所有请求设超时。
2. 脚本输出和文档里**不得出现密钥**，请求头打印时把 `Authorization` 替换成 `***`。
3. 每次真实请求，保存一份脱敏后的请求和响应样例到 `backend/docs/probes/<依赖>.json`（响应过长可截断，注明截断）。
4. 汇总写到 `backend/docs/外部依赖实测.md`，每个依赖一节：
   - 结论：可用 / 不可用 / 无法确认 / 阻塞
   - 实测的请求方式（方法、URL、关键参数）
   - 真实返回字段表（字段名、类型、示例值、是否稳定出现）
   - 实测耗时
   - 与教程描述的差异
   - 对 PRD 的影响和建议（例如：P2 不存在，则 F17 降级只能在 Tavily 与另一引擎之间做，建议候选是什么）
5. 如果你认为需要新增依赖包，用 `uv add`，并在汇报里说明。

### 不要做

- 不写流水线、接口、数据库代码（那是 M1/M2）。
- 不修改 `../frontend/`、`../docs/`、根目录文档。
- 拿不到真实响应的字段不写进字段表。

### 完成标准

- `backend/docs/外部依赖实测.md` 覆盖 P1–P4，每项都有结论和依据。
- `uv run pytest -q` 仍然通过。
- 按 `../CLAUDE.md` §4 格式汇报，附：每个探测脚本的原始运行输出（脱敏）、复现命令、「知识点素材」（比如：OpenAI 兼容接口是什么、SSE 流式 chunk 的结构、搜索 API 的 `raw_content` 为什么对 RAG 重要）。
